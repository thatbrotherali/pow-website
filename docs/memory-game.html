How it works

Study, then answer

The set shows for a few seconds, longer for bigger sets. Then either one is missing (pick it from four) or one is new (tap the newcomer).

Three ways to play

Daily: ten rounds, climbing a level each round, the same for everyone today; only your first run counts. Endless: climb a level each time you're right; three lives. Practice: nothing recorded.

Letters, numbers, shapes

Levels 1 to 4 use letters, 5 to 8 add numbers, and from level 9 shapes join in. Look-alikes such as O and 0 are left out, so every mistake is a memory slip, not a trick.
